    Class default

    Helper class that handles WebSocket Connections

    The WebSocket class is used internally by Connection to encapsulate WebSocket sessions. It is not meant to be used from user's code.

    _onMessage

    • _onMessage(message: MessageEvent<any>): void

      Private function to handle websockets messages.

      This function parses each of the messages as if they are full documents. [TODO : We may actually want to use a SAX Push parser].

      Since all XMPP traffic starts with <stream:stream version='1.0' xml:lang='en' xmlns='jabber:client' xmlns:stream='http://etherx.jabber.org/streams' id='3697395463' from='SERVER'>

      The first stanza will always fail to be parsed.

      Additionally, the seconds stanza will always be stream:features with the stream NS defined in the previous stanza, so we need to 'force' the inclusion of the NS in this stanza.

        The websocket message event
